# Fedi Any (static) Page (Otherwise known as activitypage-ts-kit)

[![libera manifesto](https://img.shields.io/badge/libera-manifesto-lightgrey.svg)](https://liberamanifesto.com)
[![Commitizen friendly](https://img.shields.io/badge/commitizen-friendly-brightgreen.svg)](http://commitizen.github.io/cz-cli/)

This repository is a set of packages that help implement an ActivityPub server that can run within different types of
web-worker situations to help static-page blogs get on the Fediverse.

It's incomplete as of yet.

Generated documentation is currently at: https://csjewell.github.io/activitypub-ts-kit/ but it is incomplete, as well.
