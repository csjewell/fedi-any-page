# activitypage-ts-kit

[![Coverage Status](https://coveralls.io/repos/github/csjewell/activitypub-ts-kit/badge.svg)](https://coveralls.io/github/csjewell/activitypub-ts-kit)

This repository is a set of packages that help implement an ActivityPub server
that can run within different types of web-worker situations.

It's incomplete as of yet.

Generated documentation is currently at: https://csjewell.github.io/activitypub-ts-kit/docs/
