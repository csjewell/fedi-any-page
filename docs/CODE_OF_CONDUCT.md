Participants in this project agree to abide by the following code of conduct:

> # The Hacker Code of Conduct
>
> Both this project and its maintainer(s) welcome all ideas, and are willing
> to include all people. True diversity of thought builds perspective and
> benefits all of us. Diversity depends on the presence of differing
> opinions, so this code of conduct establishes acceptable professional
> behaviour and does not police speech or opinions.
>
> - No ad-hominem attacks will be tolerated against any project maintainer,
>   contributor, or user
> - No prolonged disturbance of shared collaborative space will be tolerated
> - The values we uphold are: excellence, innovation, freedom, and fairness
>
> Violations of the above rules will be handled on a case-by-case basis,
> in a direct and reasonable way.

In regards to the first and second points above, code of conduct violations
will be judged based on actions within shared collaborative space ONLY.

(also on the [documentation site](http://fedi-any-page.curtisjewell.dev/docs/code-of-conduct/))
